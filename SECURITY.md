# Security Policy

## Supported Versions

Only the latest version of CloudGuard Autopilot is currently supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of CloudGuard Autopilot seriously. If you find a security vulnerability, please do not report it in the public issue tracker. Instead, please follow the steps below:

1. **Email us**: Send a detailed description of the vulnerability to **security@cloudguardai.com**.
2. **Details**: Include as much information as possible, including:
   - Type of vulnerability (e.g., XSS, SQL Injection, Auth Bypass).
   - Step-by-step instructions or proof of concept to reproduce.
   - Potential impact of the vulnerability.
3. **Response time**: We will acknowledge your report within 48 hours and work with you to remediate the vulnerability.

We ask that you follow responsible disclosure principles, giving us reasonable time to deploy a fix before disclosing any findings publicly.
